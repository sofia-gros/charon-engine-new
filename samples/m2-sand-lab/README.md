# M2 サンプル：Falling Sand Lab

M2の独立物理ライブラリ・Falling Sand Plugin・外部コリジョン・物質登録・安息角設定を確認する実験場です。正式なTilemapやGPUレンダラーは含みません。

## Windows 11で起動

Rust導入済みの環境で、リポジトリのルートから実行します。

```powershell
cargo run --release -p charon-m2-sample
```

計算周期の指定：

```powershell
cargo run --release -p charon-m2-sample -- --compute-hz 30
cargo run --release -p charon-m2-sample -- --compute-hz 60
```

ゲーム用Workerは144Hz、描画は60Hz、物理用Workerは既定45Hzです。これらは目標周期です。既存の物理がtick単位のため、30Hzと60Hzでは実時間あたりの粒子の移動速度や寿命も変わります。

## 操作

| 操作 | 入力 |
| --- | --- |
| 選択中の物質を置く | 左ドラッグ |
| 物理セルを消す | 右ドラッグ |
| ブラシの大きさ | マウスホイール |
| 砂・水・石・砂利 | 1 / 2 / 3 / 4 |
| 火・油・酸・蒸気 | 5 / 6 / 7 / 8 |
| APIで登録した土・雲・窒素 | 9 / C / N |
| 選択中の粒状物質の安息角を32° / 45°に切り替え | A |
| 物理の停止・再開 | P |
| 空の実験場へ戻す（外壁と障壁を再作成） | R |
| 中央の障壁を解除・再設置 | G |
| 中央の障壁を砂へ変換 | B |
| 終了 | Esc / ウィンドウを閉じる |

中央の青い障壁と外壁は、粒子とは別の外部コリジョンです。ブラシでは書き換えられません。Gで障壁を解除すると上の砂や水が落ち、Bでは障壁が砂へ変換されて落ちます。粒子がある位置への障壁の再設置は、全体を拒否します。下部の結果欄で `OCCUPIED` を確認できます。

物質を置く操作は空セルへの追加です。既存の粒子を別の物質で上書きしません。停止中も編集でき、再開すると物理が進みます。

## 実機確認チェックリスト

- [ ] 砂と水が落ち、中央の障壁に支えられる
- [ ] 左ドラッグで砂や水を追加でき、右ドラッグで消せる
- [ ] ブラシの物質と大きさを変更できる
- [ ] Gで障壁を開くと粒子が下へ落ちる
- [ ] 障壁上に粒子があるときの再設置が拒否され、粒子が消えない
- [ ] Rの後にBを押すと、障壁が砂になって落ちる
- [ ] Bを繰り返しても同じ障壁から砂が二重生成されない
- [ ] Pで物理が止まり、編集後に再開できる
- [ ] C・Nで登録した雲・窒素を配置すると上へ移動する
- [ ] 9で登録した土を配置でき、Aで表示中の角度が切り替わる
- [ ] 砂の32° / 45°設定で山の広がり方が変わる
- [ ] Rで物質が消え、外壁と中央の障壁が戻る
- [ ] 計算30Hz / 60Hzの双方で、描画とゲーム用Workerが独立して動く
- [ ] 終了時にWorkerが残らない

Windows 11実機の画面・入力は別途確認が必要です。自動テストやCIのWindowsビルドとは区別して記録します。

## 自動確認

```powershell
cargo test -p charon_sand
cargo run -p charon-m2-sample --no-default-features -- --smoke-test
```

スモークテストは30Hzと60Hzの両方で、ゲーム用Workerから障壁変換を要求し、砂の生成量と終了を確認します。画面・マウス入力の確認の代わりにはなりません。

[APIと現在の制約](../../docs/falling-sand-api.md)も参照してください。[物質登録と安息角のAPI](../../docs/materials.md)も用意しています。砂32°・砂利40°・登録した土38°を標準とし、設定は物質ごとに変更できます。Rで粒子を消しても登録定義と角度設定は保持します。
